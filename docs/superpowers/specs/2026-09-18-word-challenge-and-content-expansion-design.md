# AKSA English Hub 词汇扩充与 Word Challenge 设计

日期：2026-09-18

## 1. 目标

本次改版将 AKSA English Hub 从带有 AI 和语音测评的综合页面，调整为以词汇、词组、课文和自适应测试为核心的公司英语学习平台。

目标包括：

- 删除 AI 助手页面、入口、资源和相关功能。
- 删除麦克风录音、发音评分、录音动画和云端测评功能。
- 保留单词与例句的“听发音”能力，供听音选词测试使用。
- 为每个单词增加至少一组英文例句和中文翻译。
- 将单词、词组和课文内容分别扩充到当前数量的至少两倍。
- 新增独立的 Word Challenge 模块，支持拼写、听音选词和综合测试。
- 保存完整的本地学习记录、错题、掌握度和进步趋势。
- 将 Topics 调整为每日更新的资讯模块，每天新增行业新闻、国际热点和节日或文化知识，并永久保留历史内容。

公网版本在全部验证通过前保持不变。

## 5. 内容数据结构

大批量内容不继续全部堆放在 `index.html`。数据拆分为职责清晰的文件：

- `data/words.js`：单词、术语、音标、释义、例句和分类。
- `data/phrases.js`：办公词组和情景表达。
- `data/lessons.js`：课文、对话、摘要和重点词汇。
- `data/topics/index.json`：Topics 永久索引、日期、分类和检索信息。
- `data/topics/YYYY-MM-DD.json`：每天新增的 3 条 Topics 正文与学习内容。
- `word-challenge.js`：出题、计分、掌握度和记录逻辑。

单词记录至少包含：

```js
{
  id: "tech-alternator",
  term: "alternator",
  ipa: "/ˈɔːltəneɪtə/",
  zh: "交流发电机",
  pinyin: "jiāo liú fā diàn jī",
  category: "technical",
  topic: "generator-components",
  difficulty: 2,
  example: {
    en: "The alternator converts mechanical energy into electrical energy.",
    zh: "交流发电机将机械能转换为电能。"
  }
}
```

每条单词必须有唯一 `id`、英文词条、中文释义、分类、难度和中英文例句。音标和拼音允许在极少数特殊词条中为空，但数据验证会报告缺失项。

## 6. 内容扩充原则

技术词汇覆盖：发电机组部件、发动机、交流发电机、控制系统、ATS、燃油系统、冷却系统、排放、安装、调试、维护、故障、备件、安全、负载、数据中心和混合能源。

办公与日常词汇覆盖：邮件、会议、报价、订单、付款、交期、物流、客户沟通、供应商沟通、项目管理、售后、工厂参观、人事、培训和日常交流。

词组不能通过简单替换主语或时间状语制造大量近似重复。每条表达要有明确场景，重复检测以标准化英文文本为准。

新增课文重点覆盖：询价、报价、技术澄清、交期、工厂参观、安装调试、故障处理、备件、保修、付款、物流、项目交接、安全和售后服务。每篇课文至少 8 句，并包含摘要、场景标签和重点词汇。

Dialogue 是成套课文和情景对话；Topics 是每日资讯和讨论材料。Topics 不计入课文篇数或课文对话句数量。

## 7. Topics 每日资讯与永久归档

### 7.1 每日内容

系统每天北京时间 08:00 自动新增一组 3 条 Topics：

1. 柴油发电机组与备用电源行业新闻：优先关注机组订单、数据中心备用电源、电网韧性、排放法规、发动机与交流发电机、ATS、维护、燃料和市场变化。
2. 国际热点：选择适合公司英语讨论、来源可靠且不依赖猎奇或未经证实信息的国际商业、科技、能源或公共事务新闻。
3. 节日或文化知识：临近中外重要节日时介绍节日背景、习俗和商务沟通；没有合适节日时使用跨文化或国际商务知识作为替代。

首页和 Topics 页面优先展示当天 3 条内容。手动触发更新也必须遵守同一天只生成一组正式记录的规则；重复执行只能补齐失败项目或更新抓取状态，不能创建重复日期。

### 7.2 单条 Topic 结构

每条 Topic 至少包含：

- 稳定且唯一的 `id`、日期和分类。
- 英文标题、中文标题和来源名称。
- 原始发布时间、来源网址和本站抓取时间。
- 适合英语学习的英文摘要或短文，以及中文提示。
- 8 至 12 个重点单词或词组，附中文释义。
- 3 个开放式讨论问题和可展开的英文回答开头。

本站只保存学习型摘要和必要的短事实，不复制完整新闻正文。所有新闻类 Topic 必须保留可点击的原始来源链接。

### 7.3 永久历史库

新增内容采用追加式保存，任何自动更新都不得覆盖或删除以前日期的 Topics。历史库永久保留全部记录，并支持：

- 按日期倒序浏览。
- 按“发电机组行业”“国际热点”“节日文化”筛选。
- 按英文标题、中文标题、摘要和关键词搜索。
- 从详情页返回原来的筛选、搜索和滚动位置。

现有 10 条静态 Topics 在改版时迁入历史库，保留原有标题、日期和学习内容，作为初始归档，不因启用每日更新而丢失。

数据按日期分文件，索引只保存列表展示和检索所需字段，避免随着历史增长一次加载全部正文。打开详情时再读取对应日期文件；当天文件和最近查看内容可由 Service Worker 缓存。

### 7.4 来源、筛选和失败处理

自动任务从配置的可靠 RSS 或公开新闻源获取候选内容，并执行以下规则：

- 发电机组行业内容使用关键词组合匹配，并优先直接涉及订单、备用电源、法规、市场和产品技术的报道。
- 国际热点必须至少具有明确来源、标题、发布时间和原文链接。
- 以规范化网址和标题去重；已归档内容不得再次入选。
- 内容缺少来源链接、发布时间或可用摘要时不进入正式 Topics。
- 当天某一分类没有合格内容时，保留清晰的“今日暂无合适内容”状态，不用低质量新闻凑数；节日分类可按 7.1 的规则使用文化知识替代。
- 抓取或写入失败时保留上一日内容作为页面备用，不修改历史索引，并在页面显示最后成功更新时间。

工作流保留手动执行入口。自动任务提交数据前运行结构、日期、重复项、来源链接和 3 类内容完整性校验；校验失败不得写入或发布。

## 8. Word Challenge 模块

### 8.1 入口和模式

用户先选择词汇范围：技术英语、办公英语、日常英语或全部。然后选择：

- 拼写测试
- 听音选词
- 综合测试

默认每轮 10 题，可选择 20 题。综合测试在同一轮中混合两种题型，并避免同一个词连续出现。

### 8.2 拼写测试

采用已确认的自适应混合方案：

- 新词和薄弱词：提供打乱的字母拼块。
- 熟悉词和已掌握词：使用键盘完整输入。
- 第一次答错可显示首字母或减少干扰字母，第二次仍错误则展示答案。
- 判断时忽略首尾空格和大小写；连字符、撇号和词间空格按标准答案处理。

### 8.3 听音选词

- 播放目标词读音，提供四个英文选项。
- 干扰项优先从相同分类、相近长度或易混淆拼写中选择。
- 同一题的四个选项不得重复，正确答案位置随机。
- 用户可重播读音，但重播不影响得分。
- 浏览器不支持朗读时，当前题替换为拼写题，不把技术故障记为答错。

### 8.4 即时反馈

每题作答后展示：

- 正确或错误状态
- 正确拼写
- 中文释义
- 英文例句和中文翻译
- 再次播放单词或例句的按钮
- 收藏或加入复习队列的按钮

反馈出现前不展示例句，避免例句泄露答案。

## 9. 自适应掌握度

每个单词在本机保存：

```js
{
  attempts: 0,
  correct: 0,
  streak: 0,
  mastery: 0,
  lastSeen: null,
  nextReview: null
}
```

掌握度范围为 0 至 100：

- 0-24：新词
- 25-49：学习中
- 50-74：熟悉
- 75-100：已掌握

计分变化：

- 字母拼块答对：`+6`
- 听音选词答对：`+8`
- 完整拼写答对：`+12`
- 任意题型答错：`-12`
- 分数始终限制在 0 至 100

复习间隔根据掌握等级设置为 1、3、7 或 14 天。出题优先级依次为：到期错词、低掌握度词、未测试新词、随机复习词。

## 10. 学习记录与报告

每次测试保存：日期、模式、分类、题数、正确数、正确率、完成时间、错词和掌握度变化。本机最多保留最近 100 次完整测试记录，更早记录只保留按日汇总。

Dashboard 增加：

- 最近正确率
- 各分类掌握率
- 已掌握词数
- 待复习词数
- 最近 7 次成绩趋势
- 错题本入口

数据默认保存在 `localStorage`，不上传服务器。若存储不可用，则本次会话仍可答题，但会提示记录无法长期保存。

## 11. 视觉系统与页面交互

### 11.1 视觉方向

采用已确认的日式现代编辑设计，以 DESIGN STUDIO K 类作品的克制排版和留白逻辑为参考，但不复制其具体页面。整站只使用黑、白和中性灰，不使用 AKSA 红、彩色渐变、彩色状态提示或装饰性色块。

- 首页首屏使用真实柴油发电机组黑白图片作为全幅主视觉，`AKSA / ENGLISH CORNER` 是第一视觉信号。
- 字体层级采用醒目的英文展示标题、清晰的功能标题和紧凑正文；字距保持为 `0`，不使用随视口宽度连续缩放的字号。
- 页面区块使用通栏、分隔线、编号和编辑式列表组织，不堆叠卡片，也不在卡片中继续嵌套卡片。
- 按钮、输入框、选项和字母拼块保持稳定尺寸，长文本在手机端自然换行，不允许横向溢出。
- 正确和错误状态使用图标、文字、边框粗细与明暗反差共同表达，不能只依赖颜色。正确状态使用实心黑底与勾号，错误状态使用白底黑色粗边与叉号。

### 11.2 平衡型动态体验

交互采用已确认的“平衡型”强度：进入页面时具有明显设计感，学习和答题过程中保持安静、快速、可预测。

- 桌面端首页主视觉提供跟随指针的圆形扫描镜头、十字准线和轻微视差。动画只改变 `transform`、`opacity` 或遮罩位置，并通过 `requestAnimationFrame` 合并指针更新，避免触发布局抖动。
- 主视觉下方提供连续滚动的学习与资讯标签带；鼠标悬停、键盘聚焦或用户启用减少动态效果时暂停滚动。
- 首页学习路径和 Topics 使用大号编号编辑列表。悬停或聚焦时行背景黑白反转、标题轻微横移，并显示明确的进入箭头。
- 内容进入视口时执行一次短距离淡入，持续时间控制在 180 至 500 毫秒；不使用循环浮动、弹跳或影响阅读的装饰动画。
- Word Challenge 只保留与操作直接相关的反馈：字母选中、答案提交、结果出现和进度更新。答题时不运行视差或持续背景动画。
- 所有鼠标悬停效果必须有键盘聚焦等价状态；触屏设备通过点击获得同一功能，不依赖悬停才能访问内容。

### 11.3 响应式与无障碍降级

- 手机和平板关闭指针扫描镜头与跟随式视差，保留静态黑白主图、稳定裁切和轻量滚动显现。
- 用户系统启用 `prefers-reduced-motion: reduce` 时，关闭扫描跟随、视差、自动滚动和滚动显现，所有内容直接显示。
- 动态脚本加载失败时，导航、内容、Topics 检索和测试流程仍可使用；交互增强不能成为访问正文的前置条件。
- 图标按钮提供可读标签或工具提示；焦点轮廓在黑、白背景上都必须清晰可见。
- 首页主图提供有意义的替代文本，并提供适合移动网络的压缩 WebP 版本；首屏媒体不依赖第三方运行时。

### 11.4 功能页面布局

测试页面保持单题聚焦：顶部显示进度、分类和退出按钮；中部显示题目；底部显示提交或下一题。桌面和手机使用同一逻辑，手机端保证输入框、字母拼块和四个选项不横向溢出。

Topics 页面顶部先展示“今日 3 条”，下方是历史工具栏和归档列表。历史工具栏在桌面端同一行展示日期、分类和搜索，在手机端自然换行；任何加载、空结果或抓取失败状态都必须有明确说明。

按钮和答题区域使用稳定尺寸，答题反馈不能推动主要控件产生明显跳动。测试结果的正确或错误状态遵循 11.1 的黑白图标、文字与边框规则。

键盘支持：`Enter` 提交或进入下一题，数字键 `1-4` 选择听音答案，焦点状态清晰可见。

## 12. 错误处理

- 数据项缺字段：构建验证失败，不允许发布。
- 测试中找不到足够干扰项：扩大到同难度词汇池，仍不足时使用全局词池。
- 浏览器朗读不可用：听音题自动替换为拼写题。
- 本地记录损坏：备份原始值、恢复为空记录，并提示用户。
- 用户中途退出：保存已完成题目的进度，但不计入完整测试趋势。
- 当日 Topics 自动更新失败：继续显示最近一次成功内容和更新时间，不覆盖历史索引。
- 历史 Topic 文件缺失或损坏：跳过该条详情并报告可恢复错误，不影响其他日期浏览。

## 13. 测试与验收

发布前必须满足：

- AI 页面、入口、文件和相关代码全部删除。
- 录音、麦克风和发音评分代码全部删除。
- 单词、词组、课文及课文句数达到表格中的最低数量。
- 每个单词都有唯一 ID、分类、难度和中英文例句。
- 英文词条、词组和课文不存在明显重复。
- 三种测试模式均可完成 10 题和 20 题流程。
- 自适应题型、掌握度增减、错题优先和复习日期逻辑通过自动测试。
- 听音不支持时的降级流程可用。
- 页面在桌面、平板和手机尺寸下无横向溢出、遮挡或不可点击控件。
- 整站颜色扫描确认只使用黑、白和中性灰；状态表达不依赖红色、绿色或任何其他彩色。
- 桌面首页扫描镜头、轻视差、连续标签带、行悬停和滚动显现运行流畅，不造成明显布局位移。
- 手机端禁用指针专属效果后，首屏构图、导航和所有功能仍完整可用。
- `prefers-reduced-motion` 模式下不出现自动或跟随式动态，内容不会因动画关闭而隐藏。
- 使用键盘能够访问导航、学习路径、Topics、测试选项和操作按钮，焦点状态始终可见。
- 首页、Vocabulary、Word Challenge、Dialogue、Dashboard 导航正常。
- Dialogue 与 Topics 在导航、标题和数据统计中保持独立，Topics 不计入课文数量。
